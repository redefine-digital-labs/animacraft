Rules

Selection logic

cannot combine with
Part rules Prevent two whole part groups from being selected together, such as two incompatible hairstyles.
Item rules Prevent specific items from being selected together, such as one hat clipping through one hairstyle.
Hair: Twin Tails cannot combine with Hat: Tall Crown

Rule Scope

What becomes enforceable

Draft: creator tests visual compatibility locally. Template publish: allowed rule schema is stored on Sui. Soul authorization: the recipe must satisfy the published rules. Trade: license and royalty rules travel with the OC.

    Docs
    
            
    On-chain rules for OC creation
    
            
    
              Animacraft keeps the maker experience simple while Sui and Walrus record Maker provenance,
              license policy, and recipe authorization. Soulidity owns the finished character and its Living Content.
            
    
          
    
        
    
        
    
          
    
            0x
            
    No backend signer
    
            
    Creators and users sign their own transactions. Public reads use Sui GraphQL, while every core write belongs to Sui objects and wallet PTBs.
    
          
    
          
    
            W
            
    Walrus as asset layer
    
            
    Style PNGs, picker icons, Maker manifests, finished OC images, and profile JSON resolve from browser-certified Walrus Quilts. Sui records bounded Quilt and patch locators.
    
          
    
          
    
            PR
            
    Open-source releases
    
            
    Production changes land through pull requests, CI checks, and CODEOWNERS review before shipping to Vercel.
    
          
    
        
    
        
    
          
    
            
    Production Architecture
    
            
    Creator to player without a backend database
    
            
    Wallets sign core writes, Walrus stores assets, and Sui verifies ownership and recipes. Published Maker events drive the public gallery without an Animacraft database.
    
          
    
          
    
        
    
        
    
          
    
            
    Creator Guide
    Build one Character Maker
    
            Maker → Part → Item → Style → PNG
          
    
          
    
            
    01Library & Maker Top
    Create or open a Maker in the library, then use Maker Top to review structure, files, rules, and release readiness.
    
            
    02Character Maker
    Work in one studio: Part is the player menu, Item is one choice, and every Style directly owns one PNG plus its position and render settings.
    
            
    03Layer Tracks
    Arrange the global back-to-front render order, then position, scale, rotate, blend, hide, solo, and confirm each bound PNG on the shared canvas.
    
            
    04Smart Color & Rules
    Create deterministic linked color channels and enforce Item or Style requirements, exclusions, parent visibility, and valid random combinations.
    
            
    05Player Test & Preflight
    Use the exact player renderer, then resolve every missing asset, unconfirmed position, invalid default, rule conflict, and compatibility issue.
    
            
    06On-chain Publish
    Prepare one Walrus quilt, register and upload it, certify availability, then publish and share the OCMaker on Sui. Interrupted stages can resume locally.
    
          
    
        
    
        
    
          
    Maker Data Model
    Where each setting belongs
    
          
    
            
    PartOne player menu category with required/optional behavior, parent visibility, icon, default Item, and selection rules.
    
            
    Item & StyleItem is one player click. Style is the required visual choice under that Item; both may carry requires/excludes rules.
    
            
    LayerTrackA global back-to-front render lane shared across Parts. Player menu order never changes visual z-order.
    
            
    Style PNGOne Style directly owns one PNG with its own transform, opacity, blend mode, visibility, locking, and optional Smart Color. The separate Layer Tracks panel only controls global back-to-front order.
    
            
    ColorChannelA deterministic gradient-map palette shared by Styles that recolor their one PNG together.
    
            
    OCMakerThe shared Sui object binds original creator, Quilt Blob ID, public Parts/Items/Colors, rules, mint economics, license policy, and archive state.
    
            
    MakerTreasuryA shared coin-typed vault receives exact native-USDC mint fees and records collection and withdrawal totals.
    
            
    MakerAdminCapThe transferable management right controls economics, withdrawals, and lifecycle. Cap ownership is separate from original art provenance.
    
          
    
        
    
        
    
          
    Protocol Boundary
    One Maker, one canonical Soul
    
          
    
            
    AnimacraftPublishes the shared Maker, USDC Treasury, transferable AdminCap, immutable recipe rules, and a one-PTB Soul mint authorization. It does not mint a finished character token.
    
            
    SoulidityConsumes the authorization, creates the only Soul, binds mandatory Soul Character and Memory Blobs, locks ownership in a personal Kiosk, and handles social and marketplace activity.
    
            
    Dedicated handoffThe certified OC profile opens Soulidity's Animacraft integration route. The downloaded handoff archive is recovery material, not a second mint path.
    
            
    Canonical adapterFree and paid Maker authorization, verified provenance, Maker resale royalty, and the Soul mint execute through the reviewed cross-package path after its Mainnet release gate is enabled.
    
          
    
        
    
        
    
          
    Maker Lifecycle
    Delete locally, archive on-chain
    
          
    
            
    Local draftIndexedDB stores wallet-scoped structure, source files, and upload checkpoints. Maker, Part, Item, Style, and Color records may be permanently deleted before publication.
    
            
    Published MakerPublication locks art, rules, and the previously certified Walrus manifest locator. The Cap holder may only change future mint economics and archive state.
    
            
    Archived MakerThe creator may archive or restore a published Maker with a wallet signature. Archive blocks new Soul authorizations while preserving existing Souls, rights snapshots, and provenance.
    
            
    Walrus retentionProduction uploads request 53 Mainnet epochs, currently about two years. Removing a local reference does not erase certified storage, but retention must be extended before expiry.
